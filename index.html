Problème de livraison du code

Ton code n'est pas arrivé, il est incomplet ou il ne fonctionne pas ? Voici les situations les plus fréquentes.

Comment se passe le paiement ?

Après l'envoi de ta demande, le montant de ton offre s'affiche avec un bouton de paiement sécurisé ou les instructions de virement. Le code est livré une fois le paiement reçu.

Je n'ai pas reçu mon code

Vérifie tes spams et l'onglet Promotions de ta boîte mail. Le code est envoyé à l'adresse indiquée dans ta demande. S'il n'est pas arrivé dans le délai choisi, signale-le avec le formulaire ci-dessous.

Le fichier est vide ou incomplet

Indique précisément ce qui manque, avec le titre de ton projet. Nous vérifions le fichier et te renvoyons une version complète.

Le code ne fonctionne pas chez moi

Si ton code est composé de plusieurs fichiers, vérifie qu'ils sont dans le même dossier et que leurs noms n'ont pas été modifiés. Copie ensuite le message d'erreur exact et envoie-le-nous.

Je veux modifier le code livré

Décris la modification souhaitée dans le formulaire. Nous te confirmerons si elle est incluse ou si elle fait l'objet d'une nouvelle demande.
